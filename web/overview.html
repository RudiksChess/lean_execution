Part I — Completeness of Propositional Natural Deduction

1.Language and meaning

Formulas are built from atomic propositions using negation and implication. A valuation assigns a truth value to each atom, and that extends to every formula by the usual truth tables. A tautology is a formula true under every valuation.

Mathematics
Formulas: $\quad \varphi ::= p \;\mid\; \neg\varphi \;\mid\; (\varphi \to \psi)$, where $p$ ranges over atoms.

Truth under a valuation $v$: $$\llbracket p\rrbracket_v = v(p),\quad \llbracket \neg\varphi\rrbracket_v = \neg\llbracket\varphi\rrbracket_v,\quad \llbracket \varphi\to\psi\rrbracket_v = \llbracket\varphi\rrbracket_v \to \llbracket\psi\rrbracket_v.$$ Tautology: $\quad \mathrm{Taut}(\varphi) \;:\equiv\; \forall v,\ \llbracket\varphi\rrbracket_v.$
Lean 4 — Syntax.lean
inductive Formula
| atom : String → Formula
| neg  : Formula → Formula
| impl : Formula → Formula → Formula

def eval (v : Valuation) : Formula → Prop
| .atom s   => v s
| .neg p    => ¬ eval v p
| .impl p q => eval v p → eval v q

def IsTautology (φ : Formula) : Prop :=
  ∀ v, eval v φ

2.The natural-deduction calculus

A judgment $\Gamma \vdash \varphi$ means "$\varphi$ is derivable from the set of assumptions $\Gamma$." The calculus is given by inference rules. Falsity $\bot$ is encoded inside the language as $\neg(p_0\to p_0)$. The last rule, classical reductio, is what makes the logic classical rather than intuitionistic.

Mathematics — inference rules
$$\dfrac{\varphi\in\Gamma}{\Gamma\vdash\varphi}\;(\text{hyp}) \qquad \dfrac{\Gamma,\varphi\vdash\psi}{\Gamma\vdash\varphi\to\psi}\;({\to}\mathrm{I})$$ $$\dfrac{\Gamma\vdash\varphi\to\psi \quad \Gamma\vdash\varphi}{\Gamma\vdash\psi}\;({\to}\mathrm{E}) \qquad \dfrac{\Gamma,\varphi\vdash\bot}{\Gamma\vdash\neg\varphi}\;({\neg}\mathrm{I})$$ $$\dfrac{\Gamma\vdash\neg\varphi \quad \Gamma\vdash\varphi}{\Gamma\vdash\bot}\;({\neg}\mathrm{E}) \qquad \dfrac{\Gamma\vdash\bot}{\Gamma\vdash\varphi}\;({\bot}\mathrm{E})$$ $$\dfrac{\Gamma,\neg\varphi\vdash\bot}{\Gamma\vdash\varphi}\;(\text{classical})$$
Lean 4 — NaturalDeduction.lean
def Bot : Formula := ~(.atom "⊥" ⟶ .atom "⊥")

inductive ND : Set Formula → Formula → Prop
| hyp       : φ ∈ Γ → ND Γ φ
| impI      : ND (insert φ Γ) ψ → ND Γ (φ ⟶ ψ)
| impE      : ND Γ (φ ⟶ ψ) → ND Γ φ → ND Γ ψ
| negI      : ND (insert φ Γ) Bot → ND Γ (~φ)
| negE      : ND Γ (~φ) → ND Γ φ → ND Γ Bot
| botE      : ND Γ Bot → ND Γ φ
| classical : ND (insert (~φ) Γ) Bot → ND Γ φ
Each inference rule is one constructor of an inductive family. A derivation of $\Gamma\vdash\varphi$ is therefore literally a finite tree of these constructors — a value the computer can hold and check, not a paragraph of prose.

3.Soundness

Everything the calculus proves is actually true: if $\varphi$ is derivable from $\Gamma$, then $\varphi$ holds under every valuation that satisfies all of $\Gamma$. (Proof: induction on the derivation tree.) In particular, theorems of the empty context are tautologies, and $\bot$ is not derivable — the system is consistent.

Mathematics
Soundness. $$\Gamma\vdash\varphi \;\Longrightarrow\; \forall v,\ \big(\textstyle\bigwedge_{\psi\in\Gamma}\llbracket\psi\rrbracket_v\big)\to\llbracket\varphi\rrbracket_v.$$ Consequences. $\;\emptyset\vdash\varphi \Rightarrow \mathrm{Taut}(\varphi)$, and $\;\emptyset\not\vdash\bot$ (consistency).
Lean 4 — NaturalDeduction.lean
theorem soundness (d : ND Γ φ) :
    ∀ v, (∀ ψ ∈ Γ, eval v ψ) → eval v φ

theorem isTautology_of_provable
    (d : ND ∅ φ) : IsTautology φ

theorem not_provable_Bot : ¬ ND ∅ Bot

4.Kalmár's lemma — the heart of completeness

Fix a valuation $v$. For an atom $p$, its signed literal is $p$ itself if $v(p)$ is true, and $\neg p$ if it is false. Collecting the signed literals of the atoms occurring in $\varphi$ gives a context $\Gamma_v$. Kalmár's lemma says this context decides $\varphi$ syntactically: it derives $\varphi$ when $v$ makes $\varphi$ true, and derives $\neg\varphi$ when $v$ makes it false. The proof is by induction on the structure of $\varphi$.

Mathematics
Signed literal: $\quad \mathrm{lit}_v(p) = \begin{cases} p & \text{if } v(p)\\ \neg p & \text{otherwise.}\end{cases}$

Literal context $\Gamma_v$ = the signed literals of the atoms of $\varphi$.

Kalmár's lemma. $$\big(\llbracket\varphi\rrbracket_v \Rightarrow \Gamma_v\vdash\varphi\big)\ \wedge\ \big(\neg\llbracket\varphi\rrbracket_v \Rightarrow \Gamma_v\vdash\neg\varphi\big).$$
Lean 4 — Completeness.lean
def lit (v : Valuation) (p : String) : Formula :=
  if v p then .atom p else ~(.atom p)

-- literal context for the atoms of φ
def litCtx (v : Valuation) : List String → Set Formula

theorem kalmar (v) (ats) (φ) (h : atoms φ ⊆ ats) :
    (eval v φ → ND (litCtx v ats) φ) ∧
    (¬ eval v φ → ND (litCtx v ats) (~φ))

5.Discharging the assumptions

Kalmár's lemma gives a derivation that still depends on the valuation, through the literal context. The discharge step removes those assumptions one atom at a time: if $\varphi$ is derivable from the literal context for every valuation, then it is derivable outright, from no assumptions. Each atom is eliminated by a classical case split (it is either true or false).

Mathematics
Discharge. For a duplicate-free list of atoms, $$\big(\forall v,\ \Gamma_v\vdash\varphi\big)\ \Longrightarrow\ \emptyset\vdash\varphi.$$ Proof: induction on the atom list; at each step combine the $v(p)=\text{true}$ and $v(p)=\text{false}$ derivations with the derived rule of proof by cases.
Lean 4 — Completeness.lean
theorem discharge (ats : List String)
    (hnd : ats.Nodup)
    (H : ∀ v, ND (litCtx v ats) φ) :
    ND ∅ φ

6.The completeness theorem

Putting the two pieces together: every tautology is derivable from the empty context. For a tautology, $\llbracket\varphi\rrbracket_v$ holds for every $v$, so Kalmár's lemma gives $\Gamma_v\vdash\varphi$ for every $v$; discharge then yields $\emptyset\vdash\varphi$. Combined with soundness, derivability and validity coincide exactly.

Mathematics
Completeness. $\quad \mathrm{Taut}(\varphi)\ \Longrightarrow\ \emptyset\vdash\varphi.$

Adequacy (soundness + completeness): $$\mathrm{Taut}(\varphi)\ \Longleftrightarrow\ \emptyset\vdash\varphi.$$
Lean 4 — Completeness.lean
theorem completeness_ND (φ) (h : IsTautology φ) :
    ND ∅ φ :=
  discharge (atoms φ).dedup _ (fun v =>
    (kalmar v _ φ _).1 (h v))

theorem soundComplete (φ) :
    IsTautology φ ↔ ND ∅ φ

7.What "verified" means here

A derivation is a finite term whose type is checked by Lean's kernel; type-checking is the verification. To be sure nothing was smuggled in, Lean reports the complete list of axioms each theorem depends on. The main results rest only on the three standard classical axioms of the Lean/Mathlib foundation — there is no admitted gap (sorry) and no postulated "oracle" completeness rule.

Part II — Correctness of Quicksort

The repository's second machine-checked development: the classical functional quicksort returns a sorted permutation of its input — proved internally, with the same axiom guarantee.

8.The algorithm and its specification

Quicksort takes the head as the pivot, splits the tail into the elements $\le$ it and those $>$ it, sorts each recursively, and concatenates them around the pivot. "Correct" means two things: the output is a permutation of the input (nothing lost or invented) and it is sorted (pairwise nondecreasing).

Mathematics
Sorted: $\;\mathrm{Sorted}(\ell)$ iff $\ell$ is pairwise $(\le)$.

$$\mathrm{qsort}(p::r)=\mathrm{qsort}(r_{\le p})\ {+}\!{+}\ p::\mathrm{qsort}(r_{>p}).$$ Specification: $\;\mathrm{qsort}(\ell)\sim\ell\ \wedge\ \mathrm{Sorted}(\mathrm{qsort}(\ell)).$
Lean — Quicksort.lean
def Sorted (l : List α) : Prop := l.Pairwise (· ≤ ·)

def quicksort : List α → List α
  | [] => []
  | p :: rest =>
      quicksort (rest.filter (fun x => decide (x ≤ p)))
        ++ p :: quicksort (rest.filter (fun x => ! decide (x ≤ p)))
  termination_by l => l.length

9.Correctness, and the same guarantee

Two lemmas, each by induction on the list's length — the output is a permutation, and the output is sorted — combine into the specification. The axiom audit returns the same verdict as Part I.

Mathematics
Correctness. $$\forall\ell,\ \ \mathrm{qsort}(\ell)\sim\ell\ \wedge\ \mathrm{Sorted}(\mathrm{qsort}(\ell)).$$ Quicksort returns a sorted permutation of its input — the full specification of a sorting algorithm.
Lean — generated certificate
theorem quicksort_correct (l : List α) :
    quicksort l ~ l ∧ Sorted (quicksort l) :=
  ⟨quicksort_perm l, quicksort_sorted l⟩
