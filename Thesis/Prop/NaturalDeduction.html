    Falsity ⊥ is encoded inside the {¬, →}-only surface language as ¬(P → P). This is semantically always false (for any valuation), so it behaves as falsity.

      inductive Thesis.Prop.ND :
      Set Formula → Formula → Prop

      Natural Deduction with contexts (Γ : Set Formula) and discharge.

      This is a genuine classical natural deduction system: there is no oracle. Completeness is proved internally (see Completeness.lean) via Kalmár's lemma.

      • hyp {Γ : Set Formula} {φ : Formula} : φ ∈ Γ → ND Γ φ
      • impI {Γ : Set Formula} {φ ψ : Formula} : ND (insert φ Γ) ψ → ND Γ (φ ⟶ ψ)
      • impE {Γ : Set Formula} {φ ψ : Formula} : ND Γ (φ ⟶ ψ) → ND Γ φ → ND Γ ψ
      • negI {Γ : Set Formula} {φ : Formula} : ND (insert φ Γ) Bot → ND Γ (~φ)
      • negE {Γ : Set Formula} {φ : Formula} : ND Γ (~φ) → ND Γ φ → ND Γ Bot
      • botE {Γ : Set Formula} {φ : Formula} : ND Γ Bot → ND Γ φ
      • classical {Γ : Set Formula} {φ : Formula} : ND (insert (~φ) Γ) Bot → ND Γ φ

        Classical reductio: from Γ,¬φ ⊢ ⊥ infer Γ ⊢ φ.
